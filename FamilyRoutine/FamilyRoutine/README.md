# Семейный распорядок (FamilyRoutine)

Android-приложение для семей с детьми 4–16 лет: автогенерация распорядка дня,
задания со звёздочками, синхронизация родитель–ребёнок и ИИ-помощник
(помогает с домашкой и просто болтает).

## Что работает

- Три типа аккаунтов в модели данных: PARENT / CHILD / TEEN.
- Автогенерация распорядка дня по возрасту (`ScheduleGenerator`).
- Шаблоны заданий по возрастным группам 4–6 / 7–9 / 10–16 (`TaskTemplates`).
- Экран ребёнка: таймлайн дня + крупные карточки заданий «Готово!» → звёздочки.
- Экран родителя: задания, распорядок, дайджест, **семейный код для синхронизации**.
- Синхронизация через Firebase Realtime Database (`FirebaseSyncRepository`):
  родитель создаёт 6-значный код → ребёнок вводит его → задания и звёздочки
  мгновенно синхронизируются между устройствами. Без настройки Firebase
  приложение работает офлайн, ничего не ломается.
- ИИ-помощник: безопасная обёртка `SafeAiAssistant` (контент-фильтр, роли
  HOMEWORK_HELPER / FRIEND / ROUTINE_COACH) + `LocalStubBackend` — работает
  без API-ключа из коробки.

## Как получить готовый APK (без Android Studio, ~10 минут)

1. Создайте репозиторий на github.com и залейте в него **всю папку проекта**
   (через «upload files» на сайте — компилировать ничего не нужно).
2. Откройте вкладку **Actions** в репозитории — запустится «Build APK»
   (файл `.github/workflows/build-apk.yml` уже в проекте).
3. Через ~10 минут внизу страницы запуска появится артефакт
   **family-routine-apk** — скачайте его. Внутри `app-debug.apk`.
4. Скопируйте apk на Android-телефон, разрешите установку из неизвестных
   источников — приложение готово.

После каждого обновления кода (новый push) APK пересобирается автоматически.

## Как включить синхронизацию (Firebase, ~15 минут, бесплатно)

1. Зайдите на console.firebase.google.com → «Добавить проект» (любое имя).
2. Добавьте приложение Android, пакет: `com.familyroutine`.
3. Скачанный `google-services.json` положите в папку `app/`.
4. В проекте раскомментируйте две строки:
   - в `build.gradle.kts` (корневом): `id("com.google.gms.google-services") version "4.4.2" apply false`
   - в `app/build.gradle.kts`: `id("com.google.gms.google-services")`
5. В консоли Firebase: Build → Realtime Database → «Создать базу данных»
   (режим «test» подходит для начала).
6. Соберите APK заново (push в GitHub). Готово: код семьи в приложении
   теперь реально соединяет два телефона.

## Как подключить настоящий ИИ

1. Создайте серверный прокси (ключ нельзя хранить в приложении!):
   приложение → ваш сервер → сервер добавляет ключ Gemini/OpenAI.
2. Реализуйте `AiBackend` (заготовка `GeminiBackend` в `ai/AiAssistant.kt`).
3. Замените `LocalStubBackend()` на `GeminiBackend(...)` в `FamilyViewModel`.

## Ближайшие шаги (не вошли в каркас)

- Родительский PIN и просмотр логов чата ребёнка с ИИ.

- Экран подростка: планер с перетаскиванием задач.
